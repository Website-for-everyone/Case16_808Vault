# 808 Vault — Студия звукозаписи и маркетплейс битов

Профессиональная цифровая звуковая рабочая станция (DAW), каталог эксклюзивных битов и система бронирования студийных сессий.

---

## 🌟 Ключевой функционал

### 1. Веб-приложение (DAW Studio UI)
- **Многоканальный микшер (Channel Strips):** 6 треков (808 Bass, Punchy Kick, Snare/Clap, Crisp Hats, Dark Melody, Master Bus). Каждый канал оснащен фейдером громкости, регулятором стерео-панорамы (Pan L/R), кнопками Mute (M) и Solo (S), а также динамическими светодиодными VU-индикаторами (зеленый / янтарный / пиковый красный).
- **Синхронизированный бесшовный A/B плеер:** Мгновенное переключение между «Сырой демкой» (Raw Unmixed) и «Финальным мастерингом» (Mastered Track) с сохранением текущей секунды воспроизведения через Web Audio API.
- **Интерактивный Canvas-осциллограф:** Визуализация волновой формы аудио (Waveform) с возможностью скраббинга и перематывания в любую точку трека.
- **Каталог треков:** Спецификации BPM, тональности (Key), тегов жанров и мгновенное прослушивание.
- **Селектор лицензий:** Прозрачная сетка тарифов (MP3 Lease, WAV Lease, Trackout Stems, Exclusive Rights) с модальным окном быстрого заказа.
- **Бронирование студии:** Онлайн-выбор студийной комнаты (Vocal Booth, Control Room, Dolby Atmos Suite), даты, времени и отправка заявки.

### 2. Telegram-бот (Aiogram 3.x)
- Инлайн-витрина сниппетов битов с деталями.
- Конструктор лицензий с расчетом стоимости.
- FSM-запись на студийную сессию с валидацией номера телефона и даты.
- Уведомления о новых заявках куратору `@Idrisov_prod`.

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск веб-приложения и API
```bash
python web/app.py
```
Веб-интерфейс будет доступен по адресу: `http://localhost:3016` (или `http://localhost:8016` в зависимости от конфигурации).

### 3. Запуск Telegram-бота
```bash
python bot/bot.py
```

### 4. Запуск тестов
```bash
pytest tests/ -v
```
