## [1.0.0-MVP] — 2026-11-11
### Добавлено
- Полнофункциональный интерактивный веб-интерфейс DAW (Digital Audio Workstation):
  - 6-канальный микшер (808 Bass, Kick, Snare, Hi-Hats, Synth Lead, Master Bus) с фейдерами громкости, регуляторами панорамы, кнопками Mute/Solo и динамическими LED VU-метрами.
  - Синхронизированный бесшовный A/B плеер («Сырая демка» / «Мастеринг») на базе Web Audio API без потери тайминга при переключении.
  - Canvas визуализатор звуковой волны с интерактивным скраббингом по таймлайну.
  - Селектор 4 типов лицензий (MP3 Lease, WAV Lease, Trackout Stems, Exclusive Rights) с модальным окном оформления.
  - Модуль онлайн-бронирования студийных сессий (Vocal Booth, Control Room, Dolby Atmos Suite).
  - FastAPI REST API эндпоинты: `/api/tracks`, `/api/licenses`, `/api/book-session`, `/api/order-license`, `/health`.
- Полнофункциональный Telegram-бот на Aiogram 3.x:
  - Инлайн-витрина сниппетов битов с параметрами BPM, Key и тегами.
  - Выбор лицензий с калькулятором стоимости и подтверждением.
  - FSM-сценарий записи на студийную сессию с выбором комнаты, даты и контактов.
  - Форматированная диспетчеризация лидов в аккаунт куратора `@Idrisov_prod`.
- Комплекс юнит- и смоук-тестов (FastAPI TestClient + Aiogram Router handlers).
